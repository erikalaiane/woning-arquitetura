## Sobre o Projeto

**WONING** é um escritório de arquitetura fictício, criado como projeto conceito para o meu portfólio.

- **Para quem:** um escritório que atende projetos residenciais e comerciais.
- **O problema:** o escritório não tinha uma vitrine que mostrasse os projetos e o processo de trabalho com clareza, e quem chegava pelo celular tinha dificuldade para entrar em contato.
- **A solução:** um site minimalista, pensado primeiro para o celular, com galeria de projetos, página de processo em etapas e contato direto.

## Como Rodar o Projeto

### Pré-requisitos

- Node.js 20.19 ou superior
- npm

### Instalação

```bash
git clone https://github.com/erikalaiane/woning-arquitetura.git
cd woning-arquitetura
npm install
npm run dev
```

Acesse [http://localhost:5173](http://localhost:5173).

## Scripts Disponíveis

```bash
npm run dev      # Inicia servidor de desenvolvimento
npm run build    # Cria build de produção
```

## Design System

### Paleta de Cores

```css
--color-concreto:         #F4F1EC  /* Fundo principal */
--color-areia:            #E7DFD3  /* Fundo de seções alternadas */
--color-grafite:          #22201D  /* Texto e títulos */
--color-oliva:            #5C6650  /* Detalhes e linhas */
--color-terracota:        #B5654A  /* Acentos e linha-assinatura */
--color-terracota-escura: #A5563B  /* Botões com texto branco */
```

### Tipografia

- **Display**: Jost — títulos, em peso leve e com espaçamento largo
- **Corpo**: DM Sans — textos corridos e descrições
